# 红笔君产品首页 · 实施决策

UI UX Pro Max 生成的 Product Demo + Features 和 Flat Design 适合本项目，采用该信息结构。品牌决策优先于数据库通用色板，沿用 DESIGN.md 的蓝白方案和原印章。

- 页面：主视觉 → 交互产品演示 → 功能卡片 → 三步流程 → 方案预览 → FAQ → 注册入口。
- 颜色：复用 --paper #f3f6fc、--ink #172b4d、--ink-2 #53657d、--link #245bd6、--line #dce4ef；红色仅用于批改和品牌。
- 排版：系统中文无衬线；品牌及原卷保留衬线。桌面 hero 64px，移动 38px；正文 16px。
- 容器 1160px，桌面左右 32px、手机 20px；间距 8px 网格；卡片圆角 16px。
- React 18 + Tailwind 3.4，tw- 前缀且不启用 preflight，避免改变已有业务界面。
- 演示数据均为合成示例；按批改/学情/练习切换，无自动播放。
- 价格未在仓库配置；展示待公布方案，不提供虚假支付、额度或团队能力承诺。
- 首页 /：未登录展示产品页，登录仍进入 Home；/welcome 始终可访问产品页。
- 使用现有 /register 和 /login；保留工作台和所有业务路由。
- 可访问性：跳过导航、可见焦点、语义按钮、44px 触控区域、reduced-motion、移动布局。
