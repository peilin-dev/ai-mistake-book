## 关键行为

- 所有业务路由需要登录。注册页不会请求需要登录的个人资料接口。
- 上传固定 `source=web`，服务端已有的网页不自动跟随前页规则保持生效。
- 照片按拍摄时间优先排序，无时间时按自然文件名；PDF 内按页码。预览可拖动或用上移/下移按钮调整。
- 图片在浏览器转换为长边不超过 2000px、质量 0.85 的 JPEG。PDF worker、HEIC 解码、ZIP 和 EXIF 依赖随构建打包，不依赖外部 CDN。
- 一批最多 200 页，超限禁止上传。展开在第 201 页停止并明确提示分批，不把被截断的列表当作完整批次。
- 上传并发最多 3；逐页显示成功、重复、失败、额度不足。429 后停止派发新上传，列出未上传页；普通失败可逐页重试。
- 上传前读取月度额度；不足时可只传剩余额度对应的前若干页。重复页以服务端结果为准，不计作新上传。
- 上传中离开和答案核对未保存时，生产入口会阻止直接切换路由并询问；关闭/刷新页面使用浏览器原生提醒。
- 确认离开上传页后中止当前请求并停止发送后续页；已被服务端接收的页仍会继续批改，可回作业页查看。
- 删除页二次确认，说明图片和批改结果不可恢复且不退额度。
- 多页答案按原始页序合并，后页覆盖同题号；重试前页不改变优先级。失败页必须重试或明确跳过后才能保存。
- 参考答案更新不会自动重算已完成批改，页面显示复核提醒。
- 个人成绩页面含姓名，不适合投影；原有课堂讲评页面继续不暴露学生姓名。AI 学习小结明确标注为推测。

## 启动与下一步验收

1. 按 `miniprogram/README.md` 启动现有后端、MySQL、Redis 和批改 Worker；确认后端现有迁移已到 `0014`。
2. 在 `web` 执行 `npm install`、`npm run dev`，默认代理 `http://127.0.0.1:8000`；如不同，用 `API_PROXY` 指定后端。
3. 按验收清单，用测试班级走一遍“注册/登录 → 建班 → 建作业 → 多页答案卷 → 混合格式上传 → 认领 → 复核 → 成绩 → 练习 → PDF”。
4. 真实验收通过后再部署；部署后的健康、子路由刷新、权限隔离和额度需要再次确认。
